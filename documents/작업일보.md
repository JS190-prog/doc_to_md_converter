- `.hwpx` 변환 지원 추가

- `.xls` 변환 지원 추가

- `1_ha.md` 파일 인코딩 문제(기존 CP949/EUC-KR) 확인
- UTF-8(BOM)으로 재저장하여 한글 깨짐 해소

1. 빌드/배포 산출물 재생성

- 기존 `build`, `dist`, `DocToMdConverter.spec` 삭제 후 재빌드

## 작업 개요

- PDF 전처리 읽기 순서 개선: XY-Cut 알고리즘 도입
- 다단 컬럼 레이아웃 문서의 읽기 순서 오류 해소

## 상세 작업 내역

1. XY-Cut 알고리즘 모듈 신규 구현

- `Sanster/xy-cut` 레포 도입 검토 → 라이선스 미지정/유지보수 중단으로 직접 구현 결정
- 논문(XYLayoutLM, arXiv:2203.06947) 기반 재귀적 프로젝션 분할 방식으로 구현
- `src/utils/xy_cut.py` 신규 생성
  - `recursive_xy_cut(boxes, indices, res)` 함수
  - Y축 프로젝션 → 수평 밴드 분할 → X축 프로젝션 → 컬럼 분할 → 재귀 적용
  - 단일 컬럼 문서에서도 기존과 동일한 결과 보장(회귀 없음)
  - 의존성: `numpy`만 사용 (추가 패키지 불필요)

1. PDF 텍스트 추출 읽기 순서 개선

- `src/converters/pdf_converter.py` 수정
- 기존: `blocks.sort(key=lambda b: b[1])` Y좌표 단순 정렬
- 변경: 텍스트 블록 필터링 후 `recursive_xy_cut()`으로 읽기 순서 결정
- 2단/3단 컬럼 PDF에서 컬럼별 순서 정확히 보장

1. OCR 엔진 읽기 순서 개선

- `src/converters/ocr_engine.py` `_build_lines()` 수정
- 기존: `items.sort(key=lambda x: x["m"]["cy"])` 단순 Y정렬
- 변경: `recursive_xy_cut()` 적용 후 기존 라인 그룹핑/토큰 결합 로직 유지
- 스캔 PDF의 다단 레이아웃도 처리 가능

## 변경 파일(주요)

- `src/utils/xy_cut.py` (신규)
- `src/converters/pdf_converter.py`
- `src/converters/ocr_engine.py`

## 확인 사항

- 추가 패키지 설치 불필요 (`numpy`는 기존 의존성)

## 작업 개요

- PaddleOCR GPU 가속 활성화 (RTX 5050 Laptop)
- CPU 전용 빌드에서 CUDA 12.9 GPU 빌드로 교체

## 상세 작업 내역

1. 문제 진단

- 실행 로그에서 `PaddleOCR initialized on CPU (MKLDNN Disabled)` 확인
- `paddle.is_compiled_with_cuda()` 반환값 `False` → CPU 전용 `paddlepaddle` 패키지 설치 상태 확인
- GPU: NVIDIA GeForce RTX 5050 Laptop GPU (CUDA Driver 13.1, 8GB VRAM)
- Python: 3.13 (miniconda)

1. 패키지 교체

- `paddlepaddle` (CPU) 제거
- `paddlepaddle-gpu==3.3.0` CUDA 12.9 빌드 설치
  - 설치 인덱스: `https://www.paddlepaddle.org.cn/packages/stable/cu129/`
  - CUDA 드라이버 13.1은 CUDA 12.9 하위 호환 적용
- `nvidia-nvjitlink-cu12` 12.6 → 12.9 업그레이드
  - 미업그레이드 시 `cusolver64_11.dll` 로드 오류 발생

1. GPU 감지 로직 개선

- `src/converters/ocr_engine.py` `__init__` 수정
- 기존: `paddle.device.get_device() != "cpu"` → 불안정한 감지 방식
- 변경: `paddle.device.cuda.device_count() > 0` → 명시적 GPU 장치 수 확인
- GPU 이름 출력 추가 (`GPU detected: NVIDIA GeForce RTX 5050 Laptop GPU`)
- CPU 전용 빌드 감지 시 안내 메시지 분기 추가
- `_device_used` 속성 추가로 현재 사용 디바이스 추적 가능

## 변경 파일(주요)

- `requirements.txt` (GPU/CPU 설치 방법 주석 추가)
- `src/converters/ocr_engine.py` (GPU 감지 로직 개선)

## 확인 사항

- `GPU detected: NVIDIA GeForce RTX 5050 Laptop GPU`
- `PaddleOCR initialized on GPU.` 정상 출력 확인

## 배포 시 유의사항

- GPU 버전은 `pip install paddlepaddle-gpu==3.3.0 -i https://www.paddlepaddle.org.cn/packages/stable/cu129/`로 별도 설치 필요
- CPU 환경 배포 시 `paddlepaddle` (CPU 빌드) 사용
